# ПОТОКОВЫЙ АНАЛИЗАТОР ФАЙЛОВ

**Потоковый анализатор файлов** - Python-пакет, позволяющий анализировать события из файлов JSONL и CSV.

Программа способна анализировать события и собирать статистику по уровням логирования и источника. Может определять первое и последнее временное событие. Результат обработки событий сохраняется в JSON-файл.

## ОБЩИЕ СВЕДЕНИЯ

- чтение событий из файлов JSONL и CSV построчно;
- сбор статистики: общее число события, уровни и источники;
- определение Топ-5 источников с наибольшим количеством ошибок *ERROR* и *CRITICAL*;
- определение самого раннего и позднего события;
- поддержка режима *--skip-invalid*, позволяющего пропускать некорректные записи не вызывая ошибки;
- обработка нескольких входных файлов и сбор общей статистики;
- сохранение статистического отчёта о событиях в JSON-отчёте;
- обработка определенных ошибок:
    - неподдерживаемый формат;
    - неверное событие;
    - неверная временная метка;
    - ошибка конфигурации CLI;

## CLI(Командная строка)

Запуск производится из командной строки, используя модуль streamstats. 

**Для запуска необходимо написать команду в формате:**

`python -m streamstats analyze INPUT [INPUT ...] --format csv|jsonl --output REPORT.json`

**Обязательные аргументы команды запуска:**
- analyze - анализ входных данных
- INPUT [INPUT ...] - путь к одному или нескольким входным файлам
- --format - формат входных данных(файл csv или jsonl)
- --output REPORT.json - формат выходных данных(json-файл)


**Использование необязательного параметра --skip-invalid позволяет продолжить обработку событий, несмотря на некорректные записи:**

`python -m streamstats analyze events.csv --format csv --output report.json --skip-invalid`

**Примечание:** в этом режиме некорректная запись пропускается и выводится предупреждение. Затем программа продолжает работать.


**Общая справка программы**
Выполните команду, которая выводит справку о доступных командах:
`python -m streamstats --help`

## ФОРМАТ ВХОДНЫХ и ВЫХОДНЫХ ДАННЫХ

1. **Входные данные**

Два формата входных данных: JSONL и CSV

**CSV-файл**
```
timestamp,level,source,message
2026-10-15T09:25:00,INFO,auth,User
2026-10-15T10:42:00,INFO,payments,failed
2026-09-15T11:10:59,CRITICAL,database,Connection
```
**Примечание:** файл должен содержать строку с названиями полей!!!

**JSONL-файл**
```
{"timestamp":"2026-10-13T14:00:56","level":"INFO","source":"auth","message":"User"}
{"timestamp":"2026-10-15T11:11:11","level":"ERROR","source":"database","message":"Payment"}
{"timestamp":"2026-09-12T00:01:10","level":"WARNING","source":"ds","message":"Connection"}
```
**Примечание:** каждая строка отвечает за одно событие!!!




2. **Выходные данные**

Результат сохраняется в JSON-файл. В файле находится статистический отчёт, содержащий обязательные параметры:
- **total_events** — общее количество всех успешных событий;
- **levels** — количество событий для каждого уровня логирования;
- **sources** — количество событий для каждого источника;
- **five_errors** — Топ-5 источников с наибольшим количеством событий уровня ERROR и CRITICAL;
- **early** — временная метка самого раннего события;
- **late** — временная метка самого позднего события;
- **skip_events** — количество некорректных записей, которые были пропущены;

**Примечание:** временные метки представлены в формате ISO 8601.




## ИСПОЛЬЗОВАНИЕ АНАЛИЗАТОРА

Для анализа различных входных данных используйте следующие команды:

**Анализ JSONL-файла или CSV-файла:**
`python -m streamstats analyze events.jsonl --format jsonl --output REPORT.json`

`python -m streamstats analyze events.csv --format csv --output REPORT.json`

**Анализ нескольких файлов:**
`python -m streamstats analyze events1.csv events2.csv --format csv --output REPORT.json`

**Использование функционала *--skip-invalid* для пропуска некорректных событий:**
``python -m streamstats analyze INPUT --format csv|jsonl --skip-invalid`
